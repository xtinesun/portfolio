Colophon

This portfolio is designed and built by Christine Noh — no templates, no page builders. Every interaction exists to reduce friction for reviewers and reward curiosity for design peers.

Type

Lora for display — balanced, symmetric serif with timeless proportions.

Plus Jakarta Sans for UI — geometric clarity at small sizes.

Color

Warm stone base with olive sage atmosphere and terracotta coral #C95840 for emphasis — tints derived from the page background so every layer stays in family.

Built lean

  • Vanilla HTML, CSS, and JavaScript — no framework
  • CSS-only product mockups — no image dependencies
  • Respects prefers-reduced-motion
  • Semantic HTML with skip links and focus-visible states

Principles
