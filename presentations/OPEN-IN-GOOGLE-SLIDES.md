# Open CS1 deck in Google Slides

File: `CS1-Creator-Studio-GoogleSlides.pptx`

## Fast path (recommended)
1. Go to [drive.google.com](https://drive.google.com)
2. **New → File upload** → choose `CS1-Creator-Studio-GoogleSlides.pptx`
3. Right-click → **Open with → Google Slides**
4. **File → Save as Google Slides**

This deck is already filled with the CS1 case-study content in a **Marketing Plan–style gradient** look (violet → magenta → coral title/section slides, soft lavender body slides, rounded cards, media placeholders).

## Optional: apply Google’s official “Marketing plan” theme on top
1. In Google Slides: **Slide → Edit theme** (or **Change theme**)
2. Or start from **Template gallery → Marketing plan**, then **File → Import slides** and import from the uploaded deck
